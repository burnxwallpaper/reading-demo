# 第929章 點一把火

第929章 點一把火

  馬背山下有一座城市，叫做賽格市。

  之前賽格市只是一個集散地，規模很小，常住人口可能連五百人都不到。

  因為馬背山上有銀礦，據說之前還有人在馬背山發現了金礦。

  但因為各種各樣的原因，金礦並沒有被發現。

  也有人說金礦其實已經被發現了，但是總統目前並不打算開發，他要把這個金礦留給自己的孩子開發。

  反正什麽傳聞都有。

  聯邦有淘金者，拉帕也有，而且也更狂熱。

  在聯邦人們不淘金可以做很多的工作，不管是做一個保安，超級市場裡的倉庫管理員，還是去工廠找一份工作，他們都能找到來錢的路子養活自己和家人。

  可在拉帕，如果人們不淘金，那麽他們很大概率是找不到工作的。

  淘金給了很多人相對體面活下去的機會，而且馬背山中一些山貨資源很豐富。

  有跑山的人在山裡收集各種山貨，然後在山下出售給本地的收購商人。

  這些收購商人拿到這些商品後，一部分會在國內銷售，賣給統治集團和特權階級。

  還有一部分，並且是相當大的一部分，會出口到聯邦去，賺取外匯。

  有資源，有紅利，自然就會有人聚集，這個集散地的規模也逐漸大了起來。

  規模一大，拉帕的政府就要介入，它從一個沒有什麽管理的集散地，逐漸的變成了一個小村子，一個城鎮。

  並且也獲得了官方的命名，賽格市。

  “賽格”只是音譯，在拉帕本地語系中，這個詞有著“灰色的森林”的意思，就如同它背後的山，連綿，晦暗，陰沉。

  給人一種無法形容的壓抑的感覺。

  因為拉帕的空氣濕度大，不管是什麽時候，馬背山都保持著很大的濕度，遠遠望過去，會給人一種它被雲霧吞進肚子裡的感覺。

  雲山霧罩，看得不那麽清楚。

  這次饑荒對馬背山下的賽格市有一定的影響，但是影響並不是很大。

  這裡的跑山人很多，他們往山裡一鑽就是十天半個月，有的甚至可能會在山裡停留一個月。

  進山前需要做足準備，其中糧食就是一個很重要的環節。

  山裡雖然有食物，但是誰都不能保證自己走的路線上，就一定能碰到能果腹的吃的，而且能持續吃很長時間。

  大多數人進山都會攜帶相當充足的糧食，比如說計劃進山一個月的，那麽至少要帶二十磅以上的糧食。

  在這裡有一種美好祝願的說法，叫做“三十磅進去，一百磅出來”，意思是帶著三十磅的食物進山，最終能帶著一百磅的山貨回來。

  還有什麽“一磅小麥一磅金”之類的，都是很美好的祝願。

  龐大的跑山群體，也造就了本地有眾多糧食的儲備，比其他城市隻多不少。

  拉帕人因為收入比較低，也沒有儲備糧食的習慣，所以大多數城市的糧食只夠維持短時間的日常食用。

  但賽格，可以維持很長一段時間。

  所以在其他城市已經出現饑荒餓死人的時候，賽格市裡的情況還行，就是糧食的價格提高了不少，而且不是本地人，很難買到糧食。

  佩德羅已經換了一副眼鏡，為此他支付了五百塊帕拉，大約是七塊多的聯邦索爾，接近一個拉帕人一個半月的工資。

  因為鏡片是進口的，拉帕的工業基礎讓他們連鏡片都造不出來。

  國家科技的發展中也沒有點出“手搓鏡片”這個科技樹，他們缺少了一個減利略，所以所有的鏡片都靠進口，甚至包括了眼鏡架。

  這些眼睛從聯邦進口過來的價格大約是一塊錢不到，聯邦成熟的工業化生產讓這些東西的價格非常的低。

  玻璃，能值多少錢？

  眼鏡腿也是衝壓件加橡膠，在這個時候都屬於廉價的工業產品。

  但是賣，卻要賣七塊多，這就是壟斷的暴利！

  換了一副眼鏡，改變了一下髮型，佩德羅就這麽正大光明的進入了賽格市。

  他們一行人行走在大街上，看著這裡的一切，到處都充斥著“政府背景”的痕跡。

  戈麥斯他們的商會也在這裡收購各種山貨和黃金礦石，特別是狗頭金。

  只有有政府背景，或者特權階級背景的商人能夠在這裡生存下去，這些山裡的山貨是主要的出口商品，必須，也只能掌握在他們這一小撮人的手中。

  作為外來者，陌生人，有不少人的目光會在佩德羅這些人身上停留片刻。

  他們的目光並不友好，因為隨著饑荒的爆發，賽格市這裡也有了一些從周圍逃難來的人。

  他們破壞了城市裡的規則，不討人喜歡。

  這次他們來的人不多，主要是觀察一下。

  五十條槍，怎麽才能發揮出最大的作用？

  佩德羅的同事，一名通用語老師一路上都皺著眉頭，此時看到這座城市的規模，以及路上的人，他明顯感覺到了壓力。

  “我實在想不到我們這麽一點人，怎麽能夠攻打這座城市，並且……控制它？”

  “上帝，那位藍斯先生一定是想要拒絕我們，所以給我們開了一個我們無法實現的難題！”

  他臉上的表情顯得很痛苦，其他人的表情也很嚴肅。

  佩德羅和他們說了，想要獲得後續的援助，就必須交上去一份合適的“試卷”。

  比起他們的沮喪，不確定，對未來的質疑，佩德羅倒是顯得非常的鎮定。

  他一點也不沮喪，甚至不會覺得這些事情做不到。

  他的同事用手肘搗了搗他，“你怎麽想的？”

  佩德羅的目光落在了街頭一些蜷縮在角落中的那些人的身上，他們很大概率是從其他地方逃過來的難民。

  還有一些本地的普通人，本身沒有什麽積蓄，加上一些糟糕的惡習，雖然他們跑山，但總是攢不到什麽錢。

  這座城市給他一種很荒誕的感覺，是一種他在其他城市都沒有感受過的氛圍。

  這裡有數不清的賭場，酒吧，紅燈區，各種能夠消磨人們意志的東西。

  以至於有時候讓佩德羅覺得這裡根本就不是偏遠的地區，這裡就是卓蘭某個街區的縮影！

  繁華，熱鬧，充滿了娛樂的氛圍。

  他能理解。

  不管是那些淘金者，還是跑山的人，他們都是在用命賺錢。

  賺到了錢肯定就有消費的欲望，找一些女孩發泄一下在山裡一呆就是十天半個月甚至是一個月的暴躁，又或者去酒吧裡喝兩杯放放松。

  本地的果酒不值錢，包括一些小廠的威士忌，都不知道。

  這裡可沒有禁酒令，一瓶威士忌也就一百多帕拉，折合聯邦索爾就一塊多。

  當然現在漲價了，大概需要兩百帕拉，因為糧食漲價了，也就三塊錢聯邦索爾的樣子。

  他們一次不需要喝一瓶，喝一杯，二十帕拉，人人都能消費得起。

  兩百塊，煙草酒精和性，就能享受到極致。

  有人對賭博感興趣，做完這些再去賭場裡玩幾把，最後輸得一乾二淨，過去半個月白乾，然後到街邊找個乾爽的地方躺下，等待下一次進山。

  這樣的人很多，他們一直在努力，但是一直都存不到錢，仿佛有一個魔咒在這裡施加到了他們的身上。

  在佩德羅來看，這些人，實際上都能算得上是他的幫手。

  他轉了一圈之後，帶著人回到了城市外。

    他們這個團隊有一千多人，但其中相當一部分都是老弱，婦女，孩子。

  真正能夠拿得出手來的成年男性，也就兩百多人。

  回到營地後，他拿著杯子灌了兩口大水，男人們也都圍了過來。

  佩德羅坐下後整理了一下白天看到的一切，“我有個計劃……”

  接下來幾天時間裡，佩德羅和幾個他身邊幾個機靈的人重新回到了賽格市中。

  他們去了本地幾個比較有名氣的賭場，然後輸掉了不少錢——

  有聯邦人的資金援助，他們的錢已經在來的路上兌換了一部分帕拉。

  每次他們輸錢之後，就會喝上兩杯，找個和他們情況類似的人多的地方坐下來，用類似抱怨的口吻猜測賭場是不是做手腳了。

  “只要我下注的錢不多，贏錢的概率就很大。”

  “可是只要我一下多，就一定輸！”

  佩德羅把自己弄得看上去醉醺醺的樣子，他手裡拿著一個酒瓶，滿身都是酒氣，大聲的抱怨著，“我輸了這麽久，就從來沒有聽說過有誰在賭場裡贏過錢！”

  “他們一定做手腳了……”

  周圍的人都有過類似的經歷，實際上賭場本身就是一場精密的數學遊戲。

  想要在賭場裡贏錢不是那麽簡單的，而且說不定他們真的動了手腳。

  就算動了，這些人也未必知道。

  就算知道了，他們也不一定敢怎麽樣。

  畢竟每個賭場的背後，都是有背景的。

  沒有背景的人根本沒有資格在這裡做生意，哪怕是那些需要幫助的女孩們，她們的背後也是有人在支持她們的。

  否則她們早就因為競爭激烈打出狗腦子了，哪還能像現在這樣的和諧？

  佩德羅的抱怨很快就引來了很多人的讚同，人在窮的時候，總會為自己落魄找原因。

  他們不願意承認是自己貪戀賭博可能存在的高回報最終輸掉了所有，他們更願意承認是賭場做了手段導致他們輸掉了本來應該贏的錢。

  這種傳聞如果只有一個人說，那麽大家也就當一件小事情，傳個幾天就消失了。

  但是今天有人說，明天有人說，一直有人說，那麽自然而然的，就會讓一些人產生“這就是真相”的感覺。

  對於底層的人來說，什麽是真相？

  真相就是大家都認可的東西，就是真相！

  是不是真的，已經沒有那麽重要了，重要的是大家都接受這個結果！

  都不需要幾天時間，賭場的生意立刻就受到了影響。

  客人來的少了，每天的營業款數量就下降了不少。

  賽格市中規模最大的賭場老板知道了這件事後，立刻就抓了兩個賭狗過來詢問他們是不是發生了什麽，以至於人們都不來賭場了。

  當他聽說有人說賭場做手腳，害所有人都輸掉了他們冒著生命危險，從馬背山上弄回來的錢之後，一時間也有些坐不住。

  要說賭場裡沒有一丁點的貓膩顯然不可能！

  哪怕是極小概率，分母無窮大，分子也是一個“1”！

  只要存在，就一定有可能會實現。

  所以為了避免這種情況出現，賭場自然有自己的應對手段。

  這就奇怪得很。

  他們搞工業，搞經濟，搞發展搞不上去，但是在壓榨民眾這方面卻能夠跟得上國際領先水平。

  甚至有些荷官還去聯邦的天堂市或者金港城，參加過荷官的學習，學習怎麽讓本來不能贏的牌，變成贏面！

  現在這些謠言損害了賭場的利益，老板帶著打手們開始滿大街搜尋那些傳謠的人。

  但結果肯定是找不到，於是一些“疑似”傳謠的人，或者參與了傳謠的人，就成為了他們的目標。

  那些人莫名其妙挨了一頓打，而賭場方面不僅沒有因此解決問題，反而讓賭場的人變得更少了！

  矛盾，就這樣開始滋生。

  緊接著又有新的謠言開始出現，有人說他們在山上弄到的一些珍貴菌子，賣給本地的商人只能賣到十五二十一磅。

  但是這些菌子出口到聯邦去，就能賣到上千塊錢帕拉一磅！

  這些商人吞掉了他們幾十倍上百倍的利潤！

  這些人還說，他們只要攢一些山貨，到時候買一張去聯邦的船票，然後在金港碼頭那邊就能把東西賣掉，這比直接賣給本地坐地商人要好得多！

  為了讓人相信這個是真實的，傳謠的人還向其他人展示了不少聯邦索爾的流通舊鈔。

  用他們的話來說，跑一趟聯邦賺到的錢，頂得上他們在這裡乾一年的！

  一想到那麽多的錢被黑心商人轉走了，這些拿命往山裡鑽的人，就不幹了，他們紛紛要求本地商人的回收價格升上去。

  不說把利潤的大部分都讓給他們這些跑山人，至少對半分！

  這些謠言同樣觸動了本地商人們的利益，他們就是靠壓榨剝削來賺取大量經濟利益的！

  現在被人戳穿了，有些人帶著山貨出來後，剛準備賣，就被它們的親朋好友拉走了。

  然後根據他們得到的一些情報，計算他們帶出來的一袋子山貨能賣多少多少錢！

  還有更多的類似的小故事不斷在賽格市中突然開始流傳，原本穩定的秩序，一下子就變得混亂起來。

  就連那些需要幫助的女孩也出了不少謠言，像是什麽這些女人實際上是被拐賣或者綁架來的，她們並不是自願的之類的。

  讓人們在找這些女孩之前，想想他們的家人，他們家中的女性……

  “法克！”，油光水亮的頭髮反射著水晶吊燈的光芒，市長用力拍打了一下桌子，用略帶著地方口音的話，罵了一句。

  他眼睛瞪得滾圓的，看著房間裡的這些人，“到底是誰他媽在和我們作對？”

  “已經半個多月了，難道你們一點都沒有發現嗎？”

  房間裡坐著的都是本地的頭頭腦腦，每個人的表情都不好看，他們的生意出現了大幅度的暴跌。

  賺不到錢不說，他們背後的人，可能也會因此對他們有很大的意見。

  每個人心中都背著一股火，想要毀滅什麽，但又沒有一個明確的目標。

  市長來回走了幾步，“現在最重要的是讓秩序恢復。”

  他一轉頭看向這些人，“讓糧食漲價。”

  “他們不是不願意賣東西，不願意去賭場，不願意去紅燈區，不願意把他們的錢留下來嗎？”

  “那就讓糧食漲價，現在我們的小麥一磅多少錢？”

  其中一名商人說道，“一磅小麥要三塊七帕拉。”

  這比半年前增加了三倍，驚人的漲幅！

  市長雙手撐在桌面上，前傾著身體看著這些人，“漲到十塊，限量供應。”

  “並且你們要告訴他們，隨時隨地都會再漲價！”

  他看向房間裡的人，板著臉，眼睛略微的凸出來，給人一種很大的壓力的感覺，“沒有人，能把屬於我們的錢，從這裡帶出去！”

  他的手指用力在桌面上戳了戳，發出的聲音砰砰響，“沒有人！”

  “如果發現有人帶著大量物資離開……”，他抿了抿嘴，直起身，深吸了一口氣，“那就乾掉他們。”

  “謠言只要沒有被證實，就永遠只是謠言，明白我的意思嗎？”

  大家都紛紛點頭，他們當然能夠明白！

  如果有個人真的帶著山貨去了聯邦，把山貨賣掉賺了大錢，只要他回來，展示自己的所得。

  那麽因為跑山人，以及山貨而出現的賽格市，很快就會消亡！

  沒有了消費，這裡的一些山貨加工廠就沒有了貨源，工廠要停工，工人要解散。

  沒有工作的工人們只能離開這裡去其他地方尋找機會，原本聚集起來的人會逐漸的散掉，最終又回歸最初的狀態。

  只是一個集散地！

  所以無論是出於任何原因，為了任何目的，這些人都不能離開這裡！

  (本章完)
